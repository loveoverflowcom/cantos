# Cantos Studio mobile — out of scope / not implemented

Cantos Studio is web-only. Do not implement, scaffold, build or maintain a mobile client unless explicitly requested in a future roadmap.

This directory retains this scope notice only. It is not a workspace member, Gradle module,
deployment target, build/test target or Compose preview target. No mobile implementation exists.

Native Android/iOS listening remains supported in the product scope for
[Cantos Theatre](../../cantos-theatre/mobile/README.md). Shared contracts and UI libraries may
serve Theatre Mobile and Studio Web without creating a Studio mobile client.
