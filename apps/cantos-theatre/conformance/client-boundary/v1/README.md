# Listener boundary compatibility cases

These synthetic cases use the existing shared `ApiError` envelope from the real reserved
Theatre router and Studio host error vocabulary. They add no listener route or listener DTO.
Rust Theatre Web and Kotlin common/JVM execute the same literal file.200cannot be interpreted
as catalog/manifest success while those contracts are absent. No cookie or bearer is provided.

Kotlin embeds this file through its Gradle test-source generator, without a runtime dependency
on repository paths. Transport tests additionally drive the production JVM adapter against a
fresh local HTTP server; this is neither native playback nor a production service.
