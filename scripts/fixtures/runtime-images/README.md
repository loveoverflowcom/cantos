# Independent AVIF policy fixture

`red-2x3.avif` is synthetic solid RGB red, 2×3 pixels, 307 bytes,
SHA-256 `d200d30121283e2053867e2aa720e3b4b8e9fed50d3c006e3c893e36ed2f99d7`.
Encoded and decoded locally with Pillow12.3.0/libavif1.4.2, quality100,
4:4:4, speed4, one encoder thread. It contains no downloaded artwork or personal data.
Repository/release/inventory tests use the actual bytes; signatures establish format
identification only, never Server admission, rights, complete decoding or device support.
