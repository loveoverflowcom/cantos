# Draft: sample metadata disclosure

The [owner-approved sample slice](../../../../docs/decisions/0051-metadata-only-public-discovery.md#decision) requires explicit independent Work and unit decisions, live visibility and active owner, and no playback without an eligible release. This model abstracts the six approved identities to `scope`, the accepted release policy to `released`, and source/rights/snapshot checks to the precondition for a disclosure. It does not model database transactions, authentication, bytes, source integrity, client behavior, real audio or deployment. Release eligibility is an input fact, not derived or granted here. The model is a draft expectation; a passing simulation is not implementation conformance.
